# BugHunter mascot

Small, **unofficial** visual signature for independent bug hunting and testing. It is not an official logo of JEM or any other project.

Asset: `mascot-128.webp` (128 x 128 px), optimized for a small GitHub issue footer.

Example for an issue:

```html
<img src="https://raw.githubusercontent.com/koelmanlabs/joomla-distribution/main/assets/bughunter/mascot-128.webp" alt="BugHunter (unofficial)" width="90">
```

Use sparingly at the bottom of a new bug report. Keep technical details, reproduction steps, versions, and test evidence as the focus. Do not retrofit existing issues or add the mascot to routine review comments.
